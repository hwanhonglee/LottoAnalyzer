# 육사오 데이터랩

Windows 배포 버전: **9.9.7**. 실행 파일은 이 저장소의 `LottoAnalyzer.exe`입니다.

[화면 11장 보기](previews/9.9.7/README.md) · [자세한 사용 안내](README.txt) · [개인정보처리방침](PRIVACY.md)

공개 6/45 회차 자료로 번호 흐름과 조합 구조를 분석하고, 번호 생성·내 번호 저장·QR 가져오기·과거 모의검증을 제공합니다. 점수 구간과 같은 모델의 무작위 기준을 비교하고, 최종 10줄·30줄의 일치 개수·등수·중복을 따로 검증합니다.

9.9.7은 모바일 분포·추세 화면을 열거나 상세 정보를 펼칠 때 발생할 수 있던 표시 오류를 수정한 공통 배포 버전입니다. Windows는 같은 버전으로 표시를 맞췄습니다. Android·iOS 공통 소스는 비공개 저장소에서 관리하며, 이 문서는 Play Console 게시나 App Store 제출 완료를 의미하지 않습니다.

점수와 순위는 적합도 지표이며 미래 당첨확률이 아닙니다. 추첨 전 고정은 기기 시각을 사용하는 로컬 기록으로 서버 공증이 아닙니다. 복권 구매·결제·당첨금 지급 기능은 제공하지 않습니다.

프로그램 파일 검증은 `verify_program_integrity.bat`를 사용합니다. 같은 폴더의 `SHA256SUMS.txt`를 기준으로 검사합니다.
